# Как собрать готовый `Деканат-Фамилия.mdb` в Microsoft Access

## 1) Создание файла
1. Откройте Microsoft Access.
2. Создайте новую пустую базу **`Деканат-Фамилия.mdb`** (формат Access 2002-2003, если требуется строго `.mdb`).

## 2) Создание таблиц и данных
1. Откройте SQL View (Конструктор запроса → SQL-режим).
2. Выполните содержимое `schema_access.sql` блоками:
   - сначала все `CREATE TABLE`
   - затем `INSERT`.

## 3) Настройка валидаций/масок (через конструктор таблиц)

### Преподаватели
- Поле `Стаж`:
  - Validation Rule: `>0`
  - Validation Text: `Стаж должен быть больше 0`
- Поле `Телефон`:
  - Input Mask: `000-00-00`
- Поле `Дата рождения`:
  - Input Mask: `00.00.0000;0;_`
- Поле `Должность`:
  - Lookup (Value List): `профессор;доцент;старший преподаватель;ассистент`

### Студенты
- Поле `Телефон`:
  - Input Mask: `000-00-00`
- Поле `Медалист`:
  - тип Yes/No
  - Default Value: `No`

### Дисциплины
- Поле `Экзамен`:
  - Lookup (Value List): `Экз;Зач`
- Поле `Код преподавателя`:
  - можно настроить lookup на таблицу `Преподаватели` (показывать ФИО, хранить ID).

## 4) Настройка связей
Вкладка Database Tools → Relationships:
1. `Преподаватели.[Код преподавателя]` → `Дисциплины.[Код преподавателя]`
2. `Дисциплины.[Код дисциплины]` → `Оценки.[Код дисциплины]`
3. `Студенты.[Код студента]` → `Оценки.[Код студента]`

Для каждой связи включить:
- Enforce Referential Integrity
- Cascade Update Related Fields
- Cascade Delete Related Records

## 5) Импорт данных по заданию
- Импорт **Студенты** из Excel/CSV: использовать `data/students_import.csv` (или открыть в Excel и сохранить `.xlsx`).
- Импорт **Оценки** из другой БД `.mdb`:
  1. Создать отдельную БД-источник (например, `Оценки-источник.mdb`).
  2. Импортировать в неё `data/grades_source_for_import.csv` как таблицу `Оценки_источник`.
  3. В целевой `Деканат-Фамилия.mdb` выполнить External Data → Access → импорт таблицы `Оценки_источник`, затем при необходимости append в `Оценки`.
