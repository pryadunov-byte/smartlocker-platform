# База данных «Деканат» (под Microsoft Access)

В текущем Linux-контейнере отсутствует Microsoft Access/ACE Engine и недоступна установка внешних пакетов для прямой генерации бинарного `.mdb`.

Поэтому подготовлен **полный пакет для быстрого создания `Деканат-Фамилия.mdb` в Access**:

1. `schema_access.sql` — DDL/DML для создания таблиц, ключей, связей и тестовых данных.
2. `data/students_import.csv` — файл для импорта таблицы «Студенты» из Excel/CSV.
3. `data/grades_source_for_import.csv` — данные «Оценки», которые можно предварительно загрузить в отдельный `.mdb` как источник для импорта.
4. `steps.md` — пошаговый сценарий «как получить готовый `.mdb` за 10–15 минут».

## Что уже покрыто

- 4 таблицы: Преподаватели, Студенты, Дисциплины, Оценки.
- Первичные и внешние ключи.
- Связи 1:M.
- Контроль целостности (через внешние ключи).
- Валидация стажа (`> 0`).
- Форматы (рекомендованные маски/lookup) описаны в `steps.md`.
- Тестовые записи (>= 5 строк в каждой таблице).
